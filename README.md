# RCA Copilot

An agentic root-cause analysis system for retail POS and middleware estates.

I spent eight years doing root-cause analysis by hand across a distributed store
systems estate — POS, order orchestration, payments, middleware. This is an
attempt to automate the reasoning, and to measure honestly whether it works.

All log and incident data is synthetic, generated to reproduce failure modes I
have encountered in production systems.

**Status:** in progress. Currently: core data model.
